⚙️ GitHub 設定（用於直接提交回 repo）

📱 這台裝置的名稱
🙂 Face ID 解鎖

用通行密鑰的 PRF 功能：Face ID 通過後才取得解密用的秘密，密語以此加密存在這台裝置，沒通過 Face ID 解不開。需 iOS 18 / Chrome 132 以上；密語仍可隨時手動輸入。

🔁 更換密語

完成後其他裝置要改用新密語解鎖。注意：git 歷史中的舊版本仍可用舊密語解開。
